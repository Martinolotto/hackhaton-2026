|                           |                                                                                  |
| ------------------------- | -------------------------------------------------------------------------------- |
| **Factores psicológicos** | Manipulación: urgencia, miedo, presión, autoridad, recompensa, aislamiento, etc. |

|                                    |                                                                                                |
| ---------------------------------- | ---------------------------------------------------------------------------------------------- |
| **Reviews / reportes de usuarios** | Qué experiencias tuvieron otras personas con esa cuenta, vendedor, teléfono, sitio o servicio. |

|                |                                                                                                     |
| -------------- | --------------------------------------------------------------------------------------------------- |
| **Reputación** | Confianza acumulada: antigüedad, historial, valoración, cantidad de operaciones, denuncias previas. |

|   |   |
|---|---|
|**Identidad**|Si la persona o empresa es quien dice ser: nombre, cuenta verificada, dominio oficial, datos consistentes.|

|   |   |
|---|---|
|**Comportamiento**|Cómo actúa: cambios repentinos, insistencia, patrones repetitivos, contacto masivo, respuestas evasivas.|

|   |   |
|---|---|
|**Factores técnicos**|URLs sospechosas, dominio reciente, redirects, malware, archivos, emails falsificados, páginas clonadas.|

|   |   |
|---|---|
|**Factores transaccionales**|Cómo intenta cobrar o mover dinero: transferencias extrañas, cuentas de terceros, criptomonedas, pagos irreversibles.|

|   |   |
|---|---|
|**Contexto de la interacción**|Si el contacto era esperado, si tiene sentido que esa persona escriba, si existe una relación previa.|

|   |   |
|---|---|
|**Historial**|Actividad anterior de la cuenta: publicaciones, ventas, cambios de nombre, reportes, bloqueos, actividad anormal.|

|   |   |
|---|---|
|**Presencia digital**|Si existe información coherente sobre esa persona/empresa en otras plataformas y fuentes.|

|   |   |
|---|---|
|**Consistencia de información**|Si lo que afirma coincide con sus datos: ubicación, empresa, precios, identidad, producto, horarios, etc.|

|   |   |
|---|---|
|**Pruebas y evidencia**|Documentos, comprobantes, fotos, capturas, contratos o certificaciones y si pueden verificarse.|

|   |   |
|---|---|
|**Red de relaciones**|Con qué otras cuentas, dominios, teléfonos, wallets o perfiles está relacionado.|

|   |   |
|---|---|
|**Patrones conocidos de fraude**|Qué tanto se parece la situación a modalidades de estafa previamente identificadas.|

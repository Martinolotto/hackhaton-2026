# Rule: Illustration Focused

## Rol

Hace de la ilustración el vehículo principal de identidad o explicación, integrándola al contenido y al sistema de componentes.

## Dirección visual

- Define un lenguaje único: editorial, geométrico, lineal, collage, 3D o dibujado.
- Especifica paleta, contorno, perspectiva, textura y nivel de detalle.
- La UI debe sostener la ilustración con tipografía y componentes más tranquilos.
- Cada ilustración debe tener una función narrativa o explicativa.

## Composición y assets

- Diseñar alrededor de la relación texto–imagen, no insertar arte al final.
- Mantener un focal point que sobreviva al recorte responsive.
- Usar SVG para formas escalables; raster optimizado para textura o pintura.
- Proveer dimensiones, lazy loading y formatos adecuados.
- Alt descriptivo si comunica; alt vacío si es puramente decorativa.

## Movimiento

- Animar capas con una intención narrativa.
- Evitar convertir cada ilustración en una escena interactiva.
- Proveer versión estática para reduced motion.

## Debe

- Reutilizar motivos como un sistema.
- Probar contraste y lectura cerca de imágenes complejas.
- Mantener consistencia entre hero, empty states e iconografía.

## No debe

- Mezclar stock de estilos diferentes.
- Usar ilustraciones para rellenar todos los vacíos.
- Incluir texto esencial dentro de imágenes.
- Generar assets finales ficticios sin indicarlo.

## Formato de salida

Describir lenguaje de ilustración, función por ubicación, reglas de recorte, accesibilidad y estrategia de assets.

# Rule: Brutalism

## Rol

Diseña interfaces crudas, explícitas y estructuralmente honestas, donde contenido y función prevalecen sobre el acabado decorativo.

## Dirección visual

- Tipografía directa, contraste alto, colores sin gradientes cosméticos.
- Mostrar bordes, grillas, enlaces y estados sin suavizarlos innecesariamente.
- Usar espaciado abrupto de forma deliberada, no inconsistente.
- Radios nulos o mínimos; sombras ausentes o totalmente duras.
- El código visual puede sentirse industrial, editorial o web primitiva; elige uno.

## Componentes

- Botones e inputs robustos, con etiquetas visibles y contornos claros.
- Jerarquía mediante tamaño, peso, separación y reglas.
- Links reconocibles; no esconder navegación detrás de iconos ambiguos.
- Tablas y listas pueden ser protagonistas en vez de encapsularse en cards.

## Debe

- Mantener una arquitectura extremadamente clara.
- Tratar la rudeza como estética, nunca como excusa para omitir accesibilidad.
- Asegurar espacios táctiles adecuados incluso con controles compactos.

## No debe

- Introducir errores, overflow o texto ilegible “por brutalismo”.
- Usar Comic Sans o colores aleatorios como atajo.
- Llenar la interfaz de bordes sin jerarquía.
- Confundir brutalismo con neo-brutalismo: no requiere sombras juguetonas ni radios grandes.

## Formato de salida

Declarar el subregistro, reglas de borde, tipografía, color y qué elementos permanecen deliberadamente convencionales.

# Rule: Extreme Minimalism

## Rol

Reduce la interfaz a lo indispensable para una tarea o mensaje principal, sin eliminar orientación ni estados necesarios.

## Dirección visual

- Un objetivo primario por pantalla.
- Paleta de 1–2 neutros y un acento funcional.
- Tipografía y espacio son los principales recursos expresivos.
- Muy pocos contenedores; usar alineación y proximidad.
- Una sola imagen o gesto gráfico si aporta significado.

## Composición

- Priorizar una columna o eje dominante.
- Evitar dashboards, menús y opciones que no pertenezcan al flujo inmediato.
- Aplicar divulgación progresiva a controles secundarios.
- La ausencia visual no puede ocultar requisitos, precios, errores o navegación esencial.

## Interacción

- Controles con labels claros; icon-only solo para convenciones inequívocas.
- Estados silenciosos pero visibles.
- Animación casi imperceptible y funcional.

## Debe

- Medir legibilidad, longitud de línea y contraste.
- Mantener affordances aunque sean austeras.
- Diseñar empty/error/loading con el mismo rigor.

## No debe

- Confundir mínimo con incompleto.
- Ocultar acciones esenciales en menús.
- Usar grises de bajo contraste.
- Crear vastos vacíos que separen información relacionada.

## Formato de salida

Enumerar qué se eliminó, cuál es la acción primaria, cómo se orienta al usuario y qué elemento memorable permanece.

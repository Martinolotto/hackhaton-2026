# Rule: Y2K / Cyber-Retro

## Rol

Evoca el optimismo tecnológico y la cultura web del cambio de milenio mediante chrome, translucidez, techno-pop y grafismo digital, con usabilidad contemporánea.

## Dirección visual

- Elegir un registro: aqua futurista, cyber-industrial, web temprana o pop digital.
- Paleta con plata/chrome, negro o blanco, más 1–3 acentos eléctricos.
- Tipografía display extendida, techno o bitmap solo en títulos; cuerpo legible.
- Recursos: cápsulas, marcos técnicos, grids, estrellas, lentes y reflejos.
- Usar chrome/iridiscencia en focos, no en todo el texto.

## Composición

- Combinar paneles compactos con espacio negativo o fondos atmosféricos.
- Metadatos y labels técnicos pueden reforzar navegación si son reales.
- Usar asimetría y overlays sin perder orden DOM.
- En móvil, reducir ornamentos periféricos y mantener CTA estable.

## Movimiento

- Glints, scanlines, cursores o loops breves como acentos.
- Evitar flicker fuerte, glitches constantes y desplazamientos ilegibles.
- Reduced motion conserva la identidad mediante color y forma.

## Debe

- Comprobar contraste sobre chrome y gradientes.
- Mantener assets livianos y nítidos.
- Distinguirlo de 90s: Y2K es más pulido, futurista y translúcido.

## No debe

- Mezclar cyberpunk oscuro, Windows 95, vaporwave y kawaii sin dirección.
- Usar texto cromado para párrafos.
- Colocar decoraciones que parezcan controles.
- Añadir glitches a formularios o lectura principal.

## Formato de salida

Declarar registro Y2K, paleta, tratamiento chrome, motivos, movimiento permitido y simplificación móvil.

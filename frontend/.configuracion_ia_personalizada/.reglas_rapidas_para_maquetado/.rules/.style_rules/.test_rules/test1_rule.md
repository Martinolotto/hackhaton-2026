### <regla_estilo_swiss_bento>
**ESTILO SWISS BENTO-GRID & CLARIDAD SUPREMA (Inspirado en MobilityLab)**

**CONTEXTO DE ACTIVACIÓN:** 
Aplica esta regla cuando el usuario solicite un diseño web corporativo, institucional, de alta gama o enfocado en innovación tecnológica con una estética minimalista, estructurada y de diseño suizo (*Swiss Style*).

**DIRECTIVAS DE DISEÑO Y ESTRUCTURA:**

1. **Arquitectura Bento-Grid Modular:**
   - Abandona las listas aburridas o las filas idénticas. Utiliza una retícula asimétrica basada en CSS Grid (tipo *Bento Box*) donde las tarjetas o contenedores varíen en proporción (bloques cuadrados, rectangulares apaisados o verticales altos).
   - Los contenedores deben tener bordes sumamente limpios, colores de fondo planos y sólidos (o variaciones sutiles de grises muy claros/oscuros según el modo), evitando sombras exageradas. Prioriza el orden geométrico estricto.

2. **Tipografía de Precisión Suiza:**
   - La tipografía manda. Exige el uso de familias sans-serif geométricas o neogrotescas (como Inter, Helvetica, Plus Jakarta Sans o Roboto).
   - Establece una jerarquía de tamaños implacable: títulos masivos y limpios con pesos contrastados (ej. `font-weight: 700` muy ajustado en `letter-spacing`) frente a cuerpos de texto amplios, legibles y con interlineado generoso (`line-height: 1.6` o superior).

3. **Restricción de Color y Contraste Institucional:**
   - La paleta debe ser mayormente neutra (blancos puros, grises técnicos, negros profundos o fondos oscuros mate). 
   - El color de acento debe usarse con absoluta moderación (un solo color vibrante, como un azul eléctrico, verde laboratorio o naranja institucional) exclusivamente para llamadas a la acción, estados activos o microdetalles clave.

4. **Espaciado y "Aire" Estratégico (Whitespace):**
   - El diseño respira. No satures los elementos. Utiliza márgenes internos (`padding`) generosos dentro de cada caja del bento grid y grandes separaciones entre secciones para que la información se digiera con naturalidad.

5. **Interacciones Sutiles (Restrained Motion):**
   - Las animaciones o transiciones deben ser imperceptibles pero sofisticadas. Un `transition: all 0.3s cubic-bezier(0.16, 1, 0.3, 1)` suave al hacer hover sobre una tarjeta (un ligero desplazamiento vertical de 2px o cambio de opacidad del borde), manteniendo la sobriedad profesional.

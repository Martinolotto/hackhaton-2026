# Rule: Hero Layout

## Rol

Concentra la primera vista en una propuesta clara, una evidencia visual y una acción prioritaria.

## Estructura

- Incluir contexto/marca, headline específico, apoyo, CTA y prueba cuando exista.
- Elegir composición: centrada, texto + medio, full-bleed o editorial.
- Mantener una sola acción primaria; secundaria solo si representa otro nivel real.
- El medio apoya la promesa y no repite decorativamente el texto.
- No exigir que todo entre exactamente above the fold.

## Responsive

- Definir orden entre texto, CTA y medio.
- Evitar alturas `100vh` rígidas en móvil.
- Preservar focal point y reducir decoración periférica.
- Mantener headline sin saltos artificiales frágiles.

## Debe

- Comunicar producto, usuario y beneficio rápidamente.
- Usar prueba real; no inventar logos, cifras o testimonios.
- Reservar dimensiones para medios.
- Mantener CTA visible y foco claro.

## No debe

- Usar frases vagas tipo “eleva tu experiencia”.
- Añadir dashboard ficticio sin indicarlo.
- Colocar video pesado de reproducción obligatoria.
- Crear múltiples badges, pills y CTAs competidores.

## Formato de salida

Declarar composición, propuesta, CTA, rol del medio, primera vista móvil y elemento de prueba.

# Rule: The Z-shape (Zig-zag) Layout

## Rol

Guía una secuencia corta de atención entre extremos del viewport, adecuada para landings simples, presentaciones y pares texto–imagen.

## Estructura

- Inicio arriba a la izquierda: marca o propuesta.
- Extremo superior derecho: navegación o acción secundaria.
- Diagonal implícita: contenido visual que conduce al siguiente punto.
- Cierre inferior derecho: acción primaria o conclusión.
- Para páginas largas, repetir zig-zags como secciones alternadas sin invertir el orden semántico.

## Responsive

- En móvil, convertir el zig-zag en una secuencia estable: título, apoyo, medio, acción.
- No usar `row-reverse` si perjudica lectura o accesibilidad.
- Mantener focal points de imágenes al recortar.

## Debe

- Limitar cada Z a una idea.
- Usar contraste y dirección de imágenes para sostener el recorrido.
- Confirmar que el CTA siga visible sin interpretar el patrón.

## No debe

- Forzar diagonales decorativas para “dibujar” la Z.
- Alternar columnas tantas veces que la lectura serpentee.
- Colocar contenido indispensable en el centro del recorrido implícito.
- Basar navegación en posición visual solamente.

## Formato de salida

Declarar los cuatro puntos de atención, señal direccional, CTA final y secuencia móvil.

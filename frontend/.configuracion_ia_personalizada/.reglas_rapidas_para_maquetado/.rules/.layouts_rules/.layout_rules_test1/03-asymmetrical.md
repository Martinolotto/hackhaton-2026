# Rule: Asymmetrical Layout

## Rol

Crea tensión y dirección visual mediante pesos, escalas y posiciones desiguales sostenidos por una estructura subyacente coherente.

## Estructura

- Establece una grilla o ejes antes de introducir asimetría.
- Equilibra peso visual, no dimensiones idénticas.
- Limita los gestos dominantes a desplazamiento, escala o vacío; no todos a la vez.
- Mantén navegación, formularios y tareas críticas previsibles.
- Usa solapamiento únicamente si no afecta lectura ni interacción.

## Responsive

- Recomponer según jerarquía; no escalar la composición de escritorio.
- Reducir offsets y solapamientos en espacios estrechos.
- El orden DOM sigue el recorrido lógico, no la posición visual.
- Probar zoom y textos largos para detectar clipping.

## Debe

- Definir anclas visuales compartidas.
- Crear un punto focal inequívoco.
- Mantener zonas de descanso que compensen el peso.

## No debe

- Confundir irregularidad con aleatoriedad.
- Posicionar todo de forma absoluta.
- Alterar el orden visual de campos respecto de su tabulación.
- Romper alineaciones sin una razón perceptible.

## Formato de salida

Explicar grilla base, centro de peso, rupturas elegidas, anclas y recomposición móvil.

# Rule: Split Screen Layout

## Rol

Divide el viewport en dos experiencias de fuerte presencia visual, útiles para comparar, elegir, autenticar o relacionar narrativa y acción.

## Estructura

- Cada panel debe entenderse por sí solo y contribuir a una relación clara.
- El divisor puede ser central o desplazado; su posición expresa prioridad.
- Evita repetir encabezado, navegación o CTA sin necesidad.
- Mantén el contenido esencial dentro de una zona segura.
- Decide si ambos paneles hacen scroll juntos o de forma independiente; preferir scroll único.

## Responsive

- En móvil, convertir la división en secuencia vertical o selector explícito.
- Ordenar primero la tarea prioritaria.
- Evitar dos áreas de scroll vertical anidadas.
- Preservar el focal point de imágenes mediante `object-position`.

## Debe

- Comunicar la relación entre lados: contraste, causa/efecto, elección o contexto/acción.
- Mantener foco y tabulación coherentes.
- Resolver contenido asimétrico sin dejar un panel vacío.

## No debe

- Usar split screen solo para llenar ancho.
- Hacer que ambas mitades compitan con igual CTA.
- Cortar texto o controles cerca del divisor.
- Conservar 50/50 en pantallas estrechas.

## Formato de salida

Declarar relación entre paneles, proporción, modelo de scroll, orden móvil y tratamiento del divisor.

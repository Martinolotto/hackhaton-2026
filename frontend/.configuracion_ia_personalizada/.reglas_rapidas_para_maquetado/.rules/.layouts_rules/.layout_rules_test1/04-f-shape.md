# Rule: The F-shape Layout

## Rol

Optimiza páginas de exploración o lectura densa para el patrón frecuente de escaneo: una franja superior fuerte y un eje vertical izquierdo.

## Estructura

- Coloca identidad, título y decisiones principales en la primera franja.
- Sitúa subtítulos, filtros o resumen en una segunda franja más corta.
- Mantén señales de navegación y comienzos de contenido en el eje izquierdo.
- Usa jerarquía tipográfica y palabras iniciales informativas.
- Permite que imágenes o datos rompan el patrón para recuperar atención.

## Responsive

- En móvil, el patrón se vuelve una secuencia vertical; priorizar comienzos claros.
- Filtros secundarios pueden colapsar, conservando estado visible.
- No fijar anchos que fuercen líneas demasiado largas.

## Debe

- Diseñar para escaneo sin asumir que todos leen igual.
- Poner información decisiva al inicio de títulos y filas.
- Mantener landmarks y headings semánticos.
- Usar el patrón en contenido denso, resultados, documentación o noticias.

## No debe

- Aplicarlo como ley universal de eye tracking.
- Saturar la columna izquierda.
- Esconder acciones importantes al extremo derecho.
- Depender solo de negritas para jerarquía.

## Formato de salida

Identificar franjas, eje de escaneo, contenido prioritario, interrupciones y transformación móvil.
